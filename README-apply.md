## 変更内容

  - 情報一覧の上に「カテゴリ（項目）フィルタ」を追加。
    すべて／薬局業務／クリニック業務／治療・臨床／医療システムのボタンが並び、
    それぞれ件数付き。クリックするとそのカテゴリだけに絞り込める。
  - 同じ場所に「情報源フィルタ」（プルダウン）も追加。
    PMDA・厚労省・Minds・学会・沢井製薬・日医工など、今データに含まれている
    情報源の中から選んで絞り込める。
  - この2つのフィルタは、既存の「全件一覧／要確認／変更あり／重要情報（確定）／
    取得エラー」タブと組み合わせて使える（両方の条件で絞り込まれる）。
    各タブの件数バッジも、フィルタ後の件数に連動する。
  - 「カテゴリ：すべて」を選んでいるとき（初期状態）は、一覧が
    薬局業務／クリニック業務／治療・臨床／医療システムの見出しで
    自動的にグループ分けされて表示される（＝「項目別にまとめる」）。
    特定のカテゴリを選んだ時はそのカテゴリだけなのでグループ分けは行わない。
