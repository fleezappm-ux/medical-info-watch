# 実データ取得 PoC（実証段階）v2

申し送りメモ「必須3：情報取得の実証」に対応する調査結果と実装。
v1（EUC-JPのHTML一覧をスクレイピング）は実際に動作したが、v2ではもっと良い方法に切り替えた。

## 調査結果（重要・更新）

### PMDA 回収情報は年度・クラスごとのCSVでまとめて取得できる

- `https://www.info.pmda.go.jp/kaisyuu/rcidx{年度2桁}-{クラス}{区分}.csv`
  （区分：m=医薬品等／k=医療機器。例：2026年度クラスI医薬品等 → `rcidx26-1m.csv`）
- **文字コードはUTF-8（BOM付き）。文字化けしない。**
- 一覧の情報だけでなく、「回収理由」「危惧される具体的な健康被害」「回収開始日」
  「効能・効果」「担当者連絡先」など、個別の「回収の概要」ページに載っている
  詳細項目までこの1つのCSVに含まれている。
- つまり、v1で予定していた「一覧を取得→各行の詳細ページを個別に取得」という
  2段階の仕組みが不要になった。CSV1本で完結する。
- 列見出し：回収番号／掲載年月日／種類／回収概要作成日及び訂正日／クラス分類／
  一般的名称及び販売名／対象ロット・数量・出荷時期／製造販売業者等名称／回収理由／
  危惧される具体的な健康被害／回収開始日／効能・効果又は用途等／その他／
  担当者及び連絡先／備考

### 厚生労働省 医薬品供給状況（v1と同じ、変更なし）

新システム（`iyakuhin-kyokyu.mhlw.go.jp`）はbot対策でブロックされるため、
今回のPoCでは見送り。別途、取得方法を調査する必要がある。

## 今回作ったもの（v2）

`gas/pmda-recall-fetcher.gs`

PMDA回収情報（医薬品等・2026年度クラスI）のCSVを取得し、スプレッドシートへ書き出すGASスクリプト。

**使い方**

1. Googleスプレッドシートを開く（v1で使ったものと同じでも、新しく作ってもOK）
2. 拡張機能 → Apps Script
3. 中身を全部消して、`gas/pmda-recall-fetcher.gs` の内容を貼り付けて保存
4. `runPmdaRecallCsvPoc` を実行
5. 「PMDA_回収情報_PoC」シートに実データが入る
   （v1で同名のシートを既に作っている場合、列の数が変わっているので
   一度そのシートを削除してから実行するのがおすすめ）

重複防止は、PMDAが発行する「回収番号」（例：`1-2489`）をそのままキーに使っている。
これは一意な番号なので、v1の複合キー（番号＋販売名＋日付）より確実。
